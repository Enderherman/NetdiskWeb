# 批量复制与 ZIP 下载

在文件页选择文件或文件夹后，工具栏提供“复制到…”和“打包下载”。支持当前页多选；搜索结果可以包含同一账户的不同目录。

复制时选择目标目录。源内容保留，新副本计入逻辑存储空间；重名自动添加序号。不能把目录复制到自己或后代，目标树和可用容量由后端再次校验。操作确认时固定选择，后台刷新列表不会更换正在提交的对象。

ZIP 下载会递归归档所选目录，保留空目录，父目录与其子项同时选择时只归档一次。确认后直接交由浏览器下载，不把整个归档读入页面内存。“已开始下载”表示请求已发起，传输结果请查看浏览器下载列表。ZIP 不支持 Range 续传，失败后重新发起。
