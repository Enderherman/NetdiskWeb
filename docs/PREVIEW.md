# 安全文件预览（v0.5.0）

点击文件名打开预览，右侧详情操作仍可独立打开。图片、PDF、常见音频/视频、UTF-8 文本与代码在应用内查看；Office、压缩包及浏览器不支持的格式提供原文件下载，不将私有文件传给第三方在线预览服务。

## 边界

- 文本和代码最多读取前 64 KiB，超出后明确标记截断。只使用 Vue 文本插值显示，不通过 `v-html`、`srcdoc` 或脚本执行文件内容。
- HTML/SVG 只显示转义后的源文本或提供下载，不能作为网页、SVG 图片或 iframe 文档执行。
- 图片完整预览最多 20 MiB，检查 JPEG/PNG/GIF/WebP/AVIF 格式签名；伪装成图片的 HTML/SVG 不会进入图片视图。
- PDF 需真实 PDF MIME 与文件头，最多 100 MiB；使用 `pdfjs-dist` 的独立 Worker 解析并逐页绘制 canvas，不依赖 iframe 或浏览器 PDF 插件。
- PDF 仅开放前 500 页，单画布最多 400 万像素，支持分页与缩放。关闭 XFA、批注/表单交互层、全量流式读取和自动预取，不读取或执行 PDF 脚本动作。每次读取/绘制最多等待 30 秒，失败可下载。
- 音视频使用原生控件和服务端 Range，不自动播放，不整文件加载进前端内存；编码兼容性取决于浏览器。
- 所有读取先检查 HTTP/业务错误。901 通知应用重新登录，902/903 显示分享失效或需要重新提取，网络错误可重试。
- 关闭会取消读取、停止原生媒体请求并释放图片 ObjectURL。下载只提示“已发起下载”，不把请求发出等同于下载完成。

## 分享复用

`PreviewModal` 接受 `file: FileItem` 及可选 `contentUrl`，发出 `close` 和 `error(ApiError)` 事件。默认使用 `/api/file/content/{fileId}`。

可显式传入 `/api/showShare/content/{shareId}/{fileId}` 或 `/api/admin/content/{userId}/{fileId}`；地址必须与当前站点同源、命中固定接口、绑定同一 fileId，不允许任意同源网页、外部地址、查询参数或 URL 片段。组件自己的下载按钮复用该授权接口的 `?download=true`。

`FileThumbnail` 只在普通文件可用且 `fileCover` 非空时读取 `/api/file/thumbnail/{fileId}`。`fileCover` 只是有无封面的信号，不能拼接成磁盘路径。分享和管理员页面可传对应固定 thumbnail 接口；加载失败恢复文件图标。

## 验证

独立快照共 103 项测试通过，覆盖外部地址拒绝、分享固定地址、权限过期、文本硬上限和转义、伪造 MIME、图片上限、PDF 分页/画布限制/任务销毁/加密降级、音视频控件、关闭取消/释放、下载降级、缩略图和 Drive 打开入口，类型检查与构建通过。

真实浏览器已验证文本、PNG、不支持格式降级、64 KiB 截断及脚本文本转义，MP3 与 640 × 360、2 秒 MP4 实播通过。两页 PDF 已成功绘制并翻页显示两页正文，最新复核记录随 UPDATELOG 更新；自动测试不代替实际页面验证。

PDF 依赖已纳入 Vite 启动预构建，避免首次打开时临时发现依赖引发整页刷新。该依赖要求 Node.js 22.13 及以上；生产构建自带本地 PDF Worker，不使用外部 CDN。

开发服务忽略 `.local` 隔离验证目录。此目录中的配置与构建输出只供测试，不应触发运行中页面刷新。
