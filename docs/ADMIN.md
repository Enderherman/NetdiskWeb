# 管理控制台

只有后端配置的管理员可以进入，侧栏入口根据真实身份显示。每次进入管理路由重新读取服务端身份；普通用户和已撤销管理员身份的用户进入明确的无权限页面。所有管理 API 仍由后端独立鉴权。

## 用户与容量

按用户 ID、昵称、邮箱、状态筛选并分页。启停前展示用户 ID；禁用会撤销旧会话，重新启用需要重新登录。容量以整数 MB 增减，确认前展示预计总容量，服务端使用最新文件、回收站和待完成上传的实际占用再次校验。

## 文件管理

从用户列表进入或输入所属用户 ID，核对用户后再读取文件。支持目录浏览、所有目录搜索和正常/回收/删除状态筛选。预览、缩略图和下载使用包含所属用户 ID 的管理员接口。回收与未就绪内容不预览。永久删除窗口明确列出所属用户、文件及递归范围，失败保留确认窗口。

## 系统设置

配置新用户默认容量、验证码邮件标题及正文。正文中的 `%s` 会替换为验证码。保存后重新读取核对；读取失败或值不一致时提示核对，不显示假成功。页面不会展示或修改 SMTP 密码。
