# 个人设置

登录后从侧栏“个人设置”或右上头像进入。昵称、用户 ID、角色与头像均从当前服务端账户读取，不拼造邮箱或身份信息。

- 修改昵称：1–20 个字符，禁止控制字符。保存成功后重新读取资料，账户栏同步更新；读回失败会提示核对，不显示假成功。
- 上传头像：选择 JPEG、PNG、GIF 或 BMP，大小大于 0 且不超过 2 MB。后端校验尺寸并重新编码；前端更新图片地址以绕过旧缓存，头像加载失败时账户栏回退为昵称首字。
- 修改密码：填写当前密码、新密码和确认密码。新密码为 8–64 位且包含字母和数字；成功后清除本地身份并进入带成功提示的登录页。后端同时撤销所有旧会话。

自动化测试覆盖资料异常、输入校验、重复提交、头像上传失败/刷新、昵称保存后读回失败、改密失败保留身份与成功退出、账户头像固定本站地址与失败回退。

2026-10-05 本地浏览器已完成真实昵称修改及重新读取、128×128 PNG 头像上传与解码、顶部头像同步、浅色页面检查。密码提交链路由组件测试及后端集成测试覆盖；浏览器未执行改密。
