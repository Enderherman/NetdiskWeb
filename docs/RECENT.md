# 最近文件

“最近文件”按更新时间汇集本人所有正常文件，不把它当作访问历史。支持分页和每页20/50/100项。

点击文件名称或“所在位置”，页面核对最新父目录链和实际分页后，进入“我的文件”、选中条目并将键盘焦点放在名称按钮。文件已移动、目录失效、定位超时或超出有界查找范围时会提示重试，不会跳到第一项冒充定位。

上传完成任务里的 `focus` 链接也复用该选择和焦点功能。相同定位参数只处理一次，后续刷新不持续抢走键盘焦点。
