# Netdisk Web

Netdisk 的独立前端，使用 Vue 3、TypeScript 和 Vite 构建，采用简洁、中性的界面风格，支持浅色、深色及跟随系统。对应后端：[Enderherman/Netdisk](https://github.com/Enderherman/Netdisk)。

**当前版本：v0.3.0（文件浏览与组织）**。已接入真实文件列表、目录、分类搜索、排序分页、新建文件夹、重命名、批量移动和移入回收站，并提供文件详情与单文件下载。保留账号认证、真实容量、响应式导航和主题设置。上传、完整在线预览、分享与回收站管理入口将在独立版本实现；页面不使用虚构文件、用户身份或容量数据。逐项验收状态见 [UPDATELOG.md](./UPDATELOG.md)。

## 本地运行

需要 Node.js 22.12 及以上。

```sh
npm ci
npm run dev
```

默认访问 `http://127.0.0.1:5173`。复制 `.env.example` 为 `.env.local` 可指定后端开发代理地址，默认代理至 `http://127.0.0.1:7090/api`。需要配套支持明文密码服务端校验和 `/accountCapabilities` 的后端版本；前端不对密码做 MD5，也不保存登录密码或会话令牌。生产构建使用 `npm run build`，产物位于 `dist/`，可通过 `npm run preview` 检查。

生产部署需使用 HTTPS，将未知前端路由回退至 `index.html`，并将 `/api` 代理到后端，使用同源 Cookie 会话。预览命令仅提供静态界面，生产环境的 API 代理需要由部署服务器配置。邮箱未配置时，后端能力接口会使注册、找回密码和发送验证码明确不可用。

## 本版本功能

- 桌面固定侧栏、手机导航抽屉、主要内容跳转与键盘焦点管理。
- 浅色、深色、跟随系统三态配色；浏览器保存偏好；多标签同步；跟随系统时实时响应设备变化。
- 外观设置页与共享主题控件。
- 登录、注册、邮箱验证码、找回密码、退出；请求中的重复提交保护与清晰中文反馈。
- 页面刷新恢复服务端会话，未登录访问自动前往登录，会话过期退回登录；限制登录后的返回地址为站内页面。
- 使用接口返回的昵称、身份和存储空间；容量加载失败可重试，退出失败不会冒充退出成功。
- 注册和找回密码使用 8–64 位、至少字母与数字的新密码规则；独立图形验证码保护邮箱发送，成功发送后显示冷却时间。
- Router、Cookie 会话 API 客户端与后端通用响应类型，业务模块按独立功能逐项接入。
- 文件列表/网格两种视图，布局偏好保存在浏览器；目录路径和筛选参数保留在地址中，支持刷新与浏览器后退。
- 分类、全目录文件名搜索、公开字段排序和分页；加载、错误、重试、空目录和无搜索结果分别显示。
- 当前目录新建文件夹，完整文件名重命名，当前页多选/全选，批量移动和移入回收站；写操作带确认或输入对话框及重复提交保护。
- 移动目标逐级浏览，排除所选目录，服务端最终校验目录归属和循环；同名移动由服务端自动加序号。
- 详情显示接口元数据；下载先申请短时凭据，再交给浏览器下载，不把整个文件加载进前端内存。

## 文件操作说明

普通浏览只显示当前目录的直接子项；分类和搜索会查询所有目录。新建文件夹请先回到具体目录。名称支持中文和空格，禁止路径分隔符、控制字符、首尾空白和跨平台保留名称。重命名输入完整文件名，改变扩展名不会转换文件格式。

“移入回收站”是可恢复删除，确认对话框会列出选中项；当前版本的恢复操作仍需后端或后续回收站界面。详情中的下载只对状态可用的普通文件开放。目录打包、上传和在线预览不属于此版本。

接口均相对于 `/api`：读取使用 `/file/loadDataList`、`/file/getFolderInfo`、`/file/loadAllFolder`；写入使用 POST `/file/newFolder`、`/file/rename`、`/file/changeFileFolder`、`/file/delFile`、`/file/createDownloadUrl/{fileId}`。字段说明见后端 [文件组织契约](https://github.com/Enderherman/Netdisk/blob/master/docs/API-FILES.md)。

## 账户接口

所有路径相对于 `/api`；POST 参数使用表单编码，认证使用服务端 Cookie 会话。

| 接口 | 用途 |
| --- | --- |
| `GET /accountCapabilities` | 查询邮箱验证是否可用 |
| `GET /checkCode?type=0` | 登录、注册、找回密码使用的图形验证码 |
| `GET /checkCode?type=1` | 发送邮箱验证码使用的独立图形验证码 |
| `POST /login` | 邮箱、原始密码、图形验证码登录 |
| `POST /sendEmailCode` | `type=0` 注册，`type=1` 找回密码 |
| `POST /register` | 邮箱、昵称、原始密码、图形码及邮件码注册 |
| `POST /resetPwd` | 邮箱、原始新密码、图形码及邮件码找回密码 |
| `GET /getUserInfo`、`GET /getUseSpace` | 当前用户和实际容量 |
| `POST /logout` | 销毁服务端会话 |
