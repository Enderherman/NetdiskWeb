# Netdisk Web

Netdisk 的独立前端，使用 Vue 3、TypeScript 和 Vite 构建，采用简洁、中性的界面风格，支持浅色、深色及跟随系统。对应后端：[Enderherman/Netdisk](https://github.com/Enderherman/Netdisk)。

**当前版本：v0.8.0（个人资料与账户设置）**。个人设置已支持昵称、头像和密码修改，顶部头像可进入设置并与服务端资料同步。文件、上传、预览、分享和回收站已接通真实后端，支持明暗模式。使用说明见 docs/ACCOUNT.md，版本验收记录见 UPDATELOG.md。

## 本地运行

需要 Node.js 22.13 及以上。

```sh
npm ci
npm run dev
```

默认访问 `http://127.0.0.1:5173`。复制 `.env.example` 为 `.env.local` 可指定后端开发代理地址，默认代理至 `http://127.0.0.1:7090/api`。需要配套支持明文密码服务端校验和 `/accountCapabilities` 的后端版本；前端不对密码做 MD5，也不保存登录密码或会话令牌。生产构建使用 `npm run build`，产物位于 `dist/`，可通过 `npm run preview` 检查。

生产部署需使用 HTTPS，将未知前端路由回退至 `index.html`，并将 `/api` 代理到后端，使用同源 Cookie 会话。预览命令仅提供静态界面，生产环境的 API 代理需要由部署服务器配置。邮箱未配置时，后端能力接口会使注册、找回密码和发送验证码明确不可用。

## 本版本功能

- 个人设置支持昵称保存后读回、头像校验上传、修改密码后撤销旧登录；头像加载失败保留昵称回退。

- 回收站分页和多选，展示回收时间与服务器保留策略；恢复优先原目录，不可用时返回全部文件。
- 永久删除仅处理选中项，清空明确作用于全部页面；两者均需勾选不可恢复确认后提交。

- 单文件或目录分享，自定义/随机提取码、1/7/30 天或永久有效；分享列表、复制链接、单项/批量撤销。
- 公共分享同时支持游客与登录用户，沿分享授权范围浏览、预览和下载，选择个人目录后保存；登录返回当前分享页。

- 桌面固定侧栏、手机导航抽屉、主要内容跳转与键盘焦点管理。
- 浅色、深色、跟随系统三态配色；浏览器保存偏好；多标签同步；跟随系统时实时响应设备变化。
- 外观设置页与共享主题控件。
- 登录、注册、邮箱验证码、找回密码、退出；请求中的重复提交保护与清晰中文反馈。
- 页面刷新恢复服务端会话，未登录访问自动前往登录，会话过期退回登录；限制登录后的返回地址为站内页面。
- 使用接口返回的昵称、身份和存储空间；容量加载失败可重试，退出失败不会冒充退出成功。
- 注册和找回密码使用 8–64 位、至少字母与数字的新密码规则；独立图形验证码保护邮箱发送，成功发送后显示冷却时间。
- Router、Cookie 会话 API 客户端与后端通用响应类型，业务模块按独立功能逐项接入。
- 文件列表/网格两种视图，布局偏好保存在浏览器；目录路径和筛选参数保留在地址中，支持刷新与浏览器后退。
- 分类、全目录文件名搜索、公开字段排序和分页；加载、错误、重试、空目录和无搜索结果分别显示。
- 当前目录新建文件夹，完整文件名重命名，当前页多选/全选，批量移动和移入回收站；写操作带确认或输入对话框及重复提交保护。
- 移动目标逐级浏览，排除所选目录，服务端最终校验目录归属和循环；同名移动由服务端自动加序号。
- 详情显示接口元数据；下载先申请短时凭据，再交给浏览器下载，不把整个文件加载进前端内存。
- 上传管理支持多文件选择/拖放、目标目录选择、真实进度与速度、暂停/继续/重试/取消；完成后刷新文件列表与真实空间。
- 刷新后查询服务器任务并重新选择同一原文件继续，校验完整 MD5、文件名、大小、目录和分片边界。
- 点击文件名预览图片、PDF、常见音视频与纯文本/代码；文本最多 64 KiB、图片最多 20 MiB，超限和不支持的格式明确降级下载。
- 缩略图只在服务端确有封面时按文件 ID 获取，加载失败显示图标；关闭预览取消读取并释放图片及媒体资源。

## 文件操作说明

普通浏览只显示当前目录的直接子项；分类和搜索会查询所有目录。新建文件夹请先回到具体目录。名称支持中文和空格，禁止路径分隔符、控制字符、首尾空白和跨平台保留名称。重命名输入完整文件名，改变扩展名不会转换文件格式。

“移入回收站”是可恢复删除，确认对话框会列出选中项；可在侧栏“回收站”选择内容并恢复；原目录不可用时回到全部文件。详情中的下载只对状态可用的普通文件开放。目录打包不属于此版本。

点击普通文件名会打开预览。文本/代码仅按 UTF-8 读取前 64 KiB，截断时明确提示；HTML/SVG 不执行，只显示源文本或提供下载。图片最多 20 MiB；PDF 最多 100 MiB，由本地 Worker 解析并逐页绘制画布，支持分页缩放而不执行文档脚本。音视频使用浏览器原生控件，编码或格式不支持时下载后查看。预览只允许同源固定文件接口，可复用分享授权地址。详细安全与资源边界见 [预览说明](./docs/PREVIEW.md)。

接口均相对于 `/api`：读取使用 `/file/loadDataList`、`/file/getFolderInfo`、`/file/loadAllFolder`；写入使用 POST `/file/newFolder`、`/file/rename`、`/file/changeFileFolder`、`/file/delFile`、`/file/createDownloadUrl/{fileId}`。字段说明见后端 [文件组织契约](https://github.com/Enderherman/Netdisk/blob/master/docs/API-FILES.md)。

## 上传与续传

从文件页点击“上传文件”会使用当前目录，也可在“上传管理”中重新选择位置。先在独立 Worker 内以 4 MiB 块计算整个文件的 MD5，再逐个以 8 MiB 分片上传；不会整文件读取进内存。一个文件最多 10000 片，实际可上传大小同时受账户空间和服务器限制。

只有服务器明确返回 `upload_finish` 或 `upload_seconds` 才显示完成。暂停会中止本页请求，已接受分片仍占临时空间；取消必须由服务器确认，已完成原件不会被删除。首片断网且没有拿到任务 ID 时，不会盲目重新创建上传，请刷新“服务器任务”，找到该任务后续传或取消。

关闭或刷新页面后，浏览器不会保留对本地原文件的访问权限。请在服务器任务中点击“选择原文件继续”，前端会重新校验原文件，并跳过服务器确认已接受的分片。恢复信息按账号保存在本地浏览器；若缺少记录且服务器还没有任何可用于确认边界的分片，会要求先取消再重新上传。退出、会话过期或切换账号会立即中止本地上传及校验，不会把前一账号的文件自动上传给新账号。

任务记录保留上传时的名称和目录；文件后来自动重名、改名或移动时，会显示当前名称，并优先通过后端返回的当前目录链打开所在目录。目录链不可用时按当前真实名称搜索，旧后端缺少定位字段时保留原任务名搜索兼容。

部署后端需支持任务列表/查询/取消接口（后端 v0.3.0 及以上），并保留开发代理的 `changeOrigin: false` 以兼容同源写请求检查。完整规则见 [上传说明](./docs/UPLOADS.md) 与后端 [上传接口契约](https://github.com/Enderherman/Netdisk/blob/master/docs/API-UPLOAD.md)。

## 账户接口

所有路径相对于 `/api`；POST 参数使用表单编码，认证使用服务端 Cookie 会话。

| 接口 | 用途 |
| --- | --- |
| `GET /accountCapabilities` | 查询邮箱验证是否可用 |
| `GET /checkCode?type=0` | 登录、注册、找回密码使用的图形验证码 |
| `GET /checkCode?type=1` | 发送邮箱验证码使用的独立图形验证码 |
| `POST /login` | 邮箱、原始密码、图形验证码登录 |
| `POST /sendEmailCode` | `type=0` 注册，`type=1` 找回密码 |
| `POST /register` | 邮箱、昵称、原始密码、图形码及邮件码注册 |
| `POST /resetPwd` | 邮箱、原始新密码、图形码及邮件码找回密码 |
| `GET /getUserInfo`、`GET /getUseSpace` | 当前用户和实际容量 |
| `POST /logout` | 销毁服务端会话 |
